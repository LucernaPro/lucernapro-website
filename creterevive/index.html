รอยร้าวเป็นเส้นยาว เทปิดให้จบในวันเดียว

รอยร้าวบนพื้นคอนกรีตที่แตกเป็นเส้นยาว — ลานจอดรถ ทางเข้าบ้าน พื้นโรงงาน ดาดฟ้าเปลือย — ตัวนี้ถูกทำมาเพื่องานนั้นโดยเฉพาะ / ในกล่องมีสองอย่าง: น้ำยาโพลิเมอร์ กับ ส่วนผสมชนิดผง ชั่งอัตราส่วนมาให้พอดีแล้ว เปิดฝา เทรวมกัน กวนให้เข้ากัน แล้วเทลงร่องได้เลย ไม่ต้องตวงอะไรทั้งนั้น / เนื้อซ่อมไหลตัวลงไปเต็มร่องเอง และเพราะมันเป็นระบบ Polymer Modified ที่ยืดหยุ่นได้ระดับหนึ่ง พื้นขยับตามอุณหภูมิแล้วรอยเดิมจึงไม่ค่อยแตกซ้ำ — ต่างจากปูนทรายธรรมดาที่ยัดลงไปแล้วอีกไม่กี่เดือนก็ร้าวกลับมาที่เดิม

ดูราคา — 1 กก. 390 บาท fส่งรูปรอยร้าวมา เราดูให้ว่าใช้ตัวนี้ได้ไหม

ทำไมถึงต้องเป็น ตัวที่เทได้

คนส่วนใหญ่ซ่อมรอยร้าวพื้นด้วยการยัดปูนลงไป แล้วก็เจอปัญหาเดิมทุกครั้ง — ปูนเข้าไม่ถึงก้นร่อง ยึดไม่ติดผนังร่อง แล้วสุดท้ายก็แตกซ้ำที่เดิม

01

เทลงไป ไม่ต้องยัด — เนื้อจึงเต็มร่องจริง

รอยร้าวบนพื้นไม่ได้เป็นร่องสี่เหลี่ยมสวยงาม มันคดเคี้ยว บีบแคบตรงกลาง แล้วบานออกข้างล่าง / การเอาเกรียงยัดปูนแห้งๆ ลงไปจึงได้แค่ปิดปากร่อง ข้างในยังโหวงอยู่ พอมีน้ำหนักกดทับก็ยุบ / ตัวนี้เป็นเนื้อไหลตัว เทลงปากร่องแล้วมันไหลลงไปหาก้นและกินเข้าซอกเอง ทั้งเส้น

02

ยืดหยุ่นได้ — พื้นขยับแล้วรอยไม่แตกซ้ำ

สาเหตุที่พื้นซ่อมแล้วร้าวกลับมาที่เดิมแทบทุกครั้ง ไม่ใช่เพราะปูนไม่แข็งพอ แต่เพราะมันแข็งเกินไปจนไม่ยอมขยับตามพื้น / คอนกรีตกลางแจ้งยืด-หดตามอุณหภูมิทุกวัน เอาของแข็งกระด้างไปอุดรอยที่กำลังขยับ = แรงไปลงที่จุดเดิม แล้วก็ปริออกที่เดิม / เนื้อของตัวนี้ยืดหยุ่นได้ระดับหนึ่ง จึงรับการขยับได้แทนที่จะแตก — นี่คือจุดขายที่แท้จริงของมัน

03

ไม่ต้องตวง ไม่ต้องคิดสูตร

ในกล่องชั่งอัตราส่วนมาให้พอดีแล้ว — เทน้ำยาทั้งกระป๋องลงในผงทั้งถุง แล้วกวน จบ / ไม่มีการ "ผสมน้ำเพิ่มนิดหน่อยให้เหลวขึ้น" ไม่มีการเทียบ A ต่อ B ไม่มีตราชั่ง / ข้อดีจริงของเรื่องนี้คือทุกกล่องออกมาเหมือนกันหมด ไม่ขึ้นกับว่าวันนั้นใครเป็นคนผสม

04

กลางแจ้งได้ แช่น้ำขังได้

ตากแดดตากฝนได้ตามปกติ และทนน้ำขังบนรอยซ่อมได้ดี — ลานจอดรถที่มีแอ่งน้ำขังหลังฝน หรือดาดฟ้าที่ระบายน้ำไม่ค่อยดี ตัวนี้อยู่ได้ / แต่ขอพูดให้ชัด: มันคือของซ่อมรอยร้าว ไม่ใช่ระบบกันซึม ปิดรอยแล้วน้ำไม่ไหลลงรอยนั้นก็จริง แต่ไม่ได้แปลว่าทั้งพื้นกันน้ำได้ — คนละงานกันคนละตัว

รอยแบบไหน ใช่ — รอยแบบไหน ไม่ใช่

ข้อนี้สำคัญที่สุดบนหน้านี้ อ่านก่อนสั่ง — เพราะตัวนี้เก่งเรื่องเดียวและเก่งมาก แต่ถ้าเอาไปใช้ผิดงาน ผลออกมาจะไม่สวยและเราไม่อยากให้คุณเสียเงินฟรี

✓

ใช่ — รอยร้าวเป็นเส้นยาว กว้างตั้งแต่ราว 1 ซม. ขึ้นไป

นี่คือหัวใจของมัน: ร่องต้องกว้างพอที่เนื้อจะไหลลงไปได้ ราว 1 ซม. ขึ้นไปคือช่วงที่มันทำงานได้ดีที่สุด / รอยแยกยาวกลางลานจอดรถ รอยแตกตามแนวเสา รอยร้าวที่ลากยาวข้ามพื้นโรงงาน รอยต่อระหว่างแผ่นพื้นที่อ้าออก — พวกนี้คืองานของมัน

✕

ไม่ใช่ — หลุมบ่อ พื้นที่แตกเป็นแอ่งกว้าง

พูดตรงๆ ไม่ต้องอ้อม: งานหลุมบ่ออย่าใช้ตัวนี้ เพราะมันถูกออกแบบให้เทลงร่องแคบๆ ไม่ใช่เทเป็นแผ่นกว้าง — เทเป็นแอ่งกว้างแล้วผิวหน้ามีโอกาสเป็นตุ่มพองขึ้นมา ซึ่งไม่สวยและต้องรื้อทำใหม่ / งานหลุมบ่อและงานปะพื้นเป็นแผ่น ให้ใช้ PatchPro ตัวนั้นทำมาเพื่อเรื่องนี้โดยตรง

✕

ไม่ใช่ — พื้นที่จะทาสีหรือเคลือบกันซึมทับทีหลัง

ถ้าแผนของคุณคือซ่อมรอยแล้วทาสีพื้นทับ หรือลงระบบกันซึมทับ ตัวที่ควรใช้ตั้งแต่ต้นคือ PatchPro ไม่ใช่ตัวนี้ / CreteRevive เกิดมาเพื่อพื้นที่ซ่อมแล้วจบ ปล่อยเปลือยไว้อย่างนั้น — พื้นปูนขัดมัน ลานจอดรถ ทางเข้าบ้าน พื้นโรงงาน ที่ไม่มีแผนจะทาอะไรทับ

✕

ไม่ใช่ — รอยเส้นผมบางๆ และงานผนัง

รอยร้าวเส้นผม (บางจนแทบสอดกระดาษไม่เข้า) เทลงไปไม่ได้เพราะเนื้อไม่มีทางลง — ทางแก้คือเจียร์เปิดร่องให้กว้างขึ้นก่อน ตามวิธีในหัวข้อวิธีใช้งาน / ส่วนงานผนังไม่ใช่งานของตัวนี้เลย เพราะเป็นเนื้อเหลวที่ต้องอาศัยแรงโน้มถ่วง ทาแนวตั้งแล้วมันไหลย้อย — ผนังใช้ FillerAce

STRAIGHT TALK — อ่านก่อนจ่ายเงิน

ตัวนี้ราคาไม่แพงและใช้ง่ายจริง
แต่มี 5 ข้อที่เราจะบอกก่อนขาย

1 ซม.ความกว้างร่องขั้นต่ำที่มันทำงานได้ดี

ข้อแรก — ผสมแล้วต้องใช้ให้หมด เก็บไม่ได้ ข้อนี้ไม่มีข้อยกเว้น: พอน้ำยาเจอผง ปฏิกิริยาเริ่มเดินทันทีและไม่มีปุ่มหยุด / ผสมกล่องไหน ต้องใช้กล่องนั้นให้หมดในรอบเดียว เก็บไว้พรุ่งนี้ไม่ได้ เติมน้ำให้เหลวกลับมาก็ไม่ได้ (เติมน้ำ = เนื้ออ่อนลงถาวร) / เพราะฉะนั้นเตรียมร่องให้เสร็จหมดก่อน แล้วค่อยผสม อย่าผสมไว้ก่อนแล้วค่อยไปนั่งขูดร่อง — นี่คือความผิดพลาดอันดับหนึ่งของงานประเภทนี้

ข้อสอง — งานหลุมบ่อ อย่าดื้อ เราเขียนไว้ข้างบนแล้วแต่ขอย้ำอีกครั้งเพราะเจอบ่อย: ลูกค้าเห็นว่ามันเทง่ายดี เลยเอาไปเทลงหลุมกว้างๆ / ผลคือผิวหน้าเป็นตุ่มพอง ต้องสกัดออกทำใหม่ เสียทั้งของเสียทั้งแรง / เส้นแบ่งง่ายๆ: ถ้ามันเป็น "เส้น" ใช้ตัวนี้ / ถ้ามันเป็น "แอ่ง" หรือ "แผ่น" ใช้ PatchPro

ข้อสาม — ร่องต้องสะอาดจริง ไม่ใช่แค่ดูสะอาด ในร่องรอยร้าวเก่ามีทั้งฝุ่นปูน เศษหินร่วน ทราย และคราบน้ำมัน ทับถมกันมาหลายปี / ถ้าเทเนื้อลงไปทับสิ่งเหล่านั้น สิ่งที่เนื้อไปเกาะคือฝุ่น ไม่ใช่คอนกรีต — แล้ววันหนึ่งมันก็หลุดออกมาทั้งเส้นเป็นเส้นยาวสวยงาม / เป่าลม ดูดฝุ่น หรือฉีดน้ำล้างแล้วรอให้หมาด ขั้นตอนนี้กินเวลานานกว่าการเทเสียอีก และมันคุ้ม

ข้อสี่ — ยืดหยุ่นได้ ไม่ได้แปลว่ายืดได้เหมือนยาง เราเขียนว่า "ยืดหยุ่นได้ระดับหนึ่ง" และคำว่า "ระดับหนึ่ง" นั้นตั้งใจใส่ / มันรับการยืด-หดของพื้นตามอุณหภูมิได้สบาย ซึ่งเป็นสาเหตุของการร้าวซ้ำ 90% ของเคส / แต่ถ้าพื้นคุณทรุดจริง — ดินข้างล่างยุบ เสาเข็มมีปัญหา รอยกว้างขึ้นเรื่อยๆ ทุกเดือน — ไม่มีของซ่อมรอยร้าวยี่ห้อไหนในโลกช่วยได้ นั่นเป็นเรื่องโครงสร้าง ต้องแก้ที่ต้นเหตุก่อน แล้วค่อยกลับมาซ่อมผิว

ข้อห้า — ผิวรอยซ่อมจะเห็นเป็นแนว ไม่ได้กลืนหายไปกับพื้น อย่าคาดหวังว่าซ่อมแล้วจะหาไม่เจอ — เนื้อใหม่กับพื้นเก่าที่ผ่านแดดผ่านฝนมาหลายปีสีไม่มีทางเท่ากัน และผิวสัมผัสก็ต่างกัน / เกณฑ์ตัดสินของงานนี้คือ "รอยหายไป พื้นกลับมาใช้งานได้ ไม่แตกซ้ำ" ไม่ใช่ "มองไม่ออกว่าเคยซ่อม" / ถ้าอยากได้พื้นหน้าเดียวกันทั้งผืนจริงๆ ทางเดียวคือซ่อมให้จบแล้วทาสีพื้นทับทั้งลาน — ซึ่งถ้าแผนเป็นแบบนั้น ให้กลับไปอ่านข้อที่บอกว่าควรใช้ PatchPro ตั้งแต่แรก

ร่องลึกมากทำยังไง

ถ้าร่องลึกจนน่าตกใจ ไม่ต้องเทเนื้อลงไปจนเต็มทั้งความลึก — เปลืองโดยไม่จำเป็นและไม่ได้แข็งแรงขึ้น / วิธีที่เราทำกันคือเททรายแห้งลงไปรองก้นร่องก่อนสักหน่อย ให้เหลือความลึกสำหรับเนื้อซ่อมด้านบนพอประมาณ แล้วค่อยเทเนื้อทับ / ทรายทำหน้าที่เป็นตัวถมเฉยๆ ส่วนงานยึดและงานรับแรงเป็นของเนื้อซ่อมชั้นบน

กวนให้เข้ากันจริงๆ แปลว่าอะไร

ไม่ใช่คนสามที กวนจนไม่มีผงเป็นก้อนหลงเหลือ และไม่มีผงแห้งติดค้างที่ก้นถังหรือขอบถัง / เอาไม้หรือเกรียงกวาดก้นถังและขอบถังเข้ามาด้วยเสมอ จุดที่คนพลาดคือมุมก้นถัง ซึ่งผงจะไปกองอยู่ตรงนั้นแล้วไม่โดนน้ำยาเลย / เนื้อที่ผสมไม่ทั่ว = แข็งไม่เท่ากันทั้งเส้น = จุดที่อ่อนที่สุดคือจุดที่จะแตกก่อน

อากาศร้อนจัด เวลาทำงานสั้นลง

เหมือนของที่เซ็ตตัวเองทุกชนิด: ยิ่งร้อน ยิ่งเซ็ตเร็ว / เทหน้างานกลางแดดเปรี้ยงตอนบ่ายสองกับเทตอนเช้าคือคนละสถานการณ์ — งานกลางแจ้งควรทำช่วงเช้าหรือช่วงเย็นเสมอ ทั้งเพื่อเวลาทำงานที่ยาวขึ้น และเพื่อไม่ให้ผิวหน้าแห้งเร็วเกินไปจนแตกลายงา

ต้องซ่อมกี่รอบ

โดยปกติรอบเดียวจบ — เทให้เต็มเสมอพื้นแล้วปล่อยบ่ม / แต่ถ้าเทแล้วเนื้อไหลลงไปหาโพรงข้างล่างจนระดับยุบลง (เกิดขึ้นได้กับรอยร้าวเก่าที่ข้างล่างโหวง) ให้เติมซ้ำได้ทันทีขณะยังไม่เซ็ต หรือรอเซ็ตแล้วเทเติมอีกรอบก็ได้ เนื้อใหม่เกาะกับเนื้อเก่าได้ดี

ทำความสะอาดเครื่องมือ

ล้างด้วยน้ำเปล่าทันทีตอนยังไม่เซ็ต — ถังผสม ใบกวน เกรียง ล้างตอนนั้นใช้เวลาไม่ถึงนาที / ปล่อยให้แข็งคาถังแล้วต้องสกัดออกอย่างเดียว ไม่มีตัวทำละลายไหนช่วยได้ เพราะแข็งแล้วมันไม่ละลายกลับ / เคล็ดลับเดิมของบ้านเรา: ใช้ถังพลาสติกใบละไม่กี่สิบบาท คุ้มกว่ามานั่งสกัดถังดีๆ ทีหลัง

จบบนหน้านี้ครบทุกตัวเลข — หัวใจของงานนี้มีอยู่สามเรื่องเท่านั้น: ร่องต้องกว้างพอและสะอาดจริง, กวนให้เข้ากันจริงๆ ทั้งก้นถัง และ ผสมแล้วเทให้หมดในรอบเดียว

  1. ประเมินก่อนว่างานคุณใช่งานของตัวนี้ไหม

    เดินดูรอยตลอดเส้นแล้วถามตัวเองสองข้อ: (1) มันเป็น "เส้น" หรือเป็น "แอ่ง" — ถ้าเป็นแอ่งหรือหลุม หยุดตรงนี้แล้วไปใช้ PatchPro / (2) จะทาสีหรือเคลือบทับทีหลังไหม — ถ้าใช่ ก็ควรใช้ PatchPro เช่นกัน / ผ่านสองข้อนี้แล้วค่อยไปต่อ

    เส้น = ใช่แอ่ง = ไม่ใช่จะทาทับ = ไม่ใช่

  2. เปิดร่องให้กว้างอย่างน้อยราว 1 ซม.

    ถ้ารอยกว้างพออยู่แล้ว ข้ามขั้นนี้ได้เลย / ถ้าเป็นรอยเส้นผมหรือรอยแคบ ให้ใช้ลูกหมูใบตัดปูน กรีดเปิดร่องตามแนวรอย ให้ได้ความกว้างราว 1–1.5 ซม. และความลึกอย่างน้อยเท่ากับความกว้าง / ทำเป็นร่องผนังตรงลงไปดีกว่าร่องรูปตัววี เพราะร่องตรงให้พื้นที่ยึดที่ผนังทั้งสองด้านมากกว่า / ฟังดูเป็นงานเพิ่ม แต่ข้ามขั้นนี้แล้วผลจะออกมาไม่ดีทุกครั้ง เพราะเนื้อไม่มีทางลงไปถึงข้างใน

    ลูกหมูใบตัดปูนกว้าง 1–1.5 ซม.ลึก ≥ ความกว้าง

  3. ทำความสะอาดร่องให้หมดจด

    เคาะเศษปูนที่ร่วนอยู่ริมร่องออกให้หมดก่อน — ถ้าเคาะแล้วยังหลุดอีก แปลว่ายังไม่ถึงเนื้อดี เคาะต่อ / จากนั้นเป่าลมหรือดูดฝุ่นออกจากก้นร่อง ฉีดน้ำล้างก็ได้ถ้าสกปรกมาก / ถ้ามีคราบน้ำมันเครื่องต้องขัดล้างออกให้หมด — น้ำมันคือศัตรูอันดับหนึ่งของการยึดเกาะ ไม่มีของซ่อมตัวไหนเกาะทับน้ำมันได้ / ก่อนเท ร่องต้องหมาดหรือแห้ง ห้ามมีน้ำขังอยู่ก้นร่อง

    เคาะเศษร่วนออกเป่าฝุ่นให้หมดห้ามมีน้ำขัง

  4. ร่องลึกมาก — รองก้นด้วยทรายก่อน

    ถ้าร่องลึกเกินความจำเป็น เททรายแห้งลงไปรองก้นร่องก่อนสักหน่อย ให้เหลือความลึกด้านบนไว้สำหรับเนื้อซ่อม / เกลี่ยทรายให้เรียบเสมอกันตลอดเส้น ไม่ให้เป็นเนินสูงต่ำ ไม่งั้นเนื้อซ่อมจะหนาไม่เท่ากันแล้วแข็งตัวไม่พร้อมกัน / ขั้นนี้ทำเฉพาะร่องที่ลึกผิดปกติ ร่องทั่วไปไม่ต้อง

    ทรายแห้งเท่านั้นเกลี่ยให้เสมอเฉพาะร่องลึก

  5. เตรียมทุกอย่างให้พร้อม ก่อนจะแตะกล่อง

    ข้อนี้ไม่ใช่คำแนะนำ เป็นกติกา: ผสมแล้วนาฬิกาเริ่มเดินทันทีและหยุดไม่ได้ / ก่อนผสม ให้แน่ใจว่า ร่องเตรียมเสร็จหมดทั้งเส้นแล้ว · ถังผสมและใบกวนอยู่ในมือแล้ว · น้ำสำหรับล้างเครื่องมือเตรียมไว้แล้ว / ถ้ารอยยาวมากจนเทไม่หมดใน 30 นาที ให้แบ่งเป็นช่วงๆ แล้วผสมทีละกล่อง ไม่ใช่ผสมรวดเดียวทั้งหมด

    เตรียมร่องให้เสร็จก่อนยาวมากให้แบ่งช่วง

  6. ผสม — เททั้งกระป๋องลงทั้งถุง แล้วกวนให้เข้ากันจริงๆ

    ไม่ต้องตวงอะไรทั้งนั้น อัตราส่วนถูกจัดมาให้พอดีในกล่องแล้ว — เทน้ำยาทั้งกระป๋องลงในผงทั้งถุง (เทน้ำยาลงก่อนแล้วค่อยโรยผงตามจะกวนง่ายกว่า) / กวนราว 2–3 นาที ด้วยสว่านใบกวนหรือมือก็ได้ / เกณฑ์ว่ากวนพอแล้ว: เนื้อเนียนเป็นครีมเดียวกันหมด ไม่มีผงเป็นก้อน และไม่มีผงแห้งค้างที่ก้นถังหรือขอบถัง — เอาเกรียงกวาดก้นถังและขอบถังเข้ามากวนด้วยเสมอ จุดนี้คือจุดที่คนพลาดกันมากที่สุด / ห้ามเติมน้ำเพื่อให้เหลวขึ้น เด็ดขาด

    ไม่ต้องตวงกวน 2–3 นาทีกวาดก้นถังด้วยห้ามเติมน้ำ

  7. เทลงร่อง — เทให้เต็มแล้วปาดหน้าเสมอพื้น

    เทลงปากร่องช้าๆ ตามแนวรอย ปล่อยให้เนื้อไหลลงไปหาก้นร่องเอง อย่ารีบเทรวดเดียวจนล้นออกนอกร่อง / เทให้เต็มจนเสมอระดับพื้น แล้วปาดหน้าด้วยเกรียงเล็กให้เรียบ เก็บส่วนที่เลอะนอกร่องออกทันทีตอนยังเปียก — แห้งแล้วขูดยาก / ถ้าเนื้อยุบลงไปเพราะข้างล่างโหวง ให้เติมซ้ำได้เลยตอนยังไม่เซ็ต เดินดูตลอดเส้นอีกรอบก่อนเลิกงานเสมอ

    เทช้าๆ ให้ไหลลงเองปาดเสมอพื้นยุบแล้วเติมซ้ำได้

  8. รอบ่ม — เดินได้ 4–6 ชม. · ใช้งานปกติ 24 ชม. · รถวิ่งผ่าน 7 วัน

    เดินเบาๆ ผ่านได้หลัง 4–6 ชั่วโมง / ใช้งานตามปกติ (เดิน วางของ ล้างพื้น) หลัง 24 ชั่วโมง / รถวิ่งทับ ของหนักกดทับ หรือแช่น้ำขังถาวร ให้รอ 7 วัน เพราะเนื้อซ่อมต้องการเวลาบ่มเต็มที่ / อากาศเย็นหรือชื้นจัดช้ากว่านี้ อากาศร้อนเร็วกว่านี้ — ไม่แน่ใจ รออีกวันเสมอ ไม่มีใครเสียหายจากการรอ / ล้างเครื่องมือด้วยน้ำเปล่าทันทีที่เลิกงาน ปล่อยแข็งคาถังแล้วสกัดอย่างเดียว

    เดินได้ 4–6 ชม.ใช้ปกติ 24 ชม.รถผ่าน 7 วันล้างน้ำเปล่าทันที
⚠ ห้ามใช้กับหลุมบ่อหรือพื้นที่แตกเป็นแอ่งกว้าง: ตัวนี้ออกแบบมาให้เทลงร่องแคบ — เทเป็นแผ่นกว้างแล้วผิวหน้ามีโอกาสเป็นตุ่มพอง ต้องสกัดออกทำใหม่ / งานหลุมบ่อและงานปะพื้นเป็นแผ่น ใช้ PatchPro
⚠ ห้ามเติมน้ำเพื่อให้เนื้อเหลวขึ้น: อัตราส่วนในกล่องคือจุดที่เนื้อแข็งแรงที่สุดแล้ว — เติมน้ำ = เนื้ออ่อนลงถาวร หดตัวมากขึ้น และแตกร้าวเองภายในไม่กี่เดือน ประหยัดวันนี้ แล้วต้องกลับมาทำใหม่
⚠ ผสมแล้วต้องใช้ให้หมด: เก็บไว้ใช้พรุ่งนี้ไม่ได้ กวนใหม่ให้เหลวกลับมาก็ไม่ได้ — เตรียมร่องให้เสร็จก่อนแล้วค่อยผสม ไม่ใช่ผสมก่อนแล้วค่อยไปเตรียมร่อง
⚠ ห้ามเทลงบนร่องที่มีน้ำขังหรือมีคราบน้ำมัน: น้ำขังทำให้เนื้อเจือจางเฉพาะจุด ส่วนน้ำมันทำให้ไม่ยึดเกาะเลย — ล้างและทำให้หมาดก่อนเสมอ
⚠ ใส่ถุงมือและแว่นตา: เนื้อที่ผสมแล้วมีฤทธิ์เป็นด่างและกัดผิวได้ โดนผิวนานๆ ระคายเคืองได้ กระเด็นเข้าตาต้องล้างน้ำสะอาดมากๆ ทันที — ถือเป็นงานเคมีก่อสร้าง ไม่ใช่งานทาสีธรรมดา
อุณหภูมิและช่วงเวลาที่ควรทำงาน: เหมือนงานเคมีที่เซ็ตตัวด้วยตัวเองทั่วไป — ยิ่งร้อน ยิ่งเซ็ตเร็ว เวลาทำงานยิ่งสั้น / งานกลางแจ้งควรทำช่วงเช้าหรือช่วงเย็น เลี่ยงการเทบนพื้นที่ร้อนจัดกลางแดดเปรี้ยง เพราะผิวหน้าจะแห้งเร็วเกินไปจนแตกลายงา / เช็กพยากรณ์อากาศก่อนเริ่มงานกลางแจ้ง — ฝนสาดลงบนรอยที่ยังไม่เซ็ตจะชะเนื้อออกและทำให้ผิวเสีย ควรมั่นใจว่าไม่มีฝนอย่างน้อย 6–8 ชั่วโมง ข้างหน้า
