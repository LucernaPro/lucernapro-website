DeepSeal กันซึม Negative Side
ซ่อมน้ำซึมจากด้านใน

ผนังร่วมทาวน์โฮม คอนโด ห้องใต้ดิน — จุดที่ออกไปซ่อมข้างนอกไม่ได้ แต่น้ำซึมเข้ามาทุกหน้าฝน DeepSeal บล็อกจากด้านในให้จบ: ส่วนผสมเดียว เปิดฝาทาได้ทันที ซึมลึกอุดถึงเนื้อคอนกรีต กลิ่นน้อย ทำงานในห้องได้สบาย และทาสีทับได้เมื่อแห้งสนิท

สั่งซื้อ / ดูราคา fปรึกษาหน้างานฟรี

ทำไมต้อง DeepSeal

งานกันซึมฝั่ง Negative คือการยืนสู้กับน้ำที่ดันมาจากหลังฟิล์ม — ระบบที่จะรอดในสนามนี้ต้องเกาะแน่นจริงและซึมลึกจริง

01

ทนแรงดันน้ำย้อนกลับ

ออกแบบมารับ Negative Hydrostatic Pressure โดยเฉพาะ — แรงยึดเกาะสูงจนฟิล์มไม่บวมพอง ไม่หลุดล่อน แม้น้ำจะดันจากด้านหลังตลอดเวลา

02

ซึมลึกอุดถึงโครงสร้าง

เนื้อสารถูกจูนให้เซ็ตตัวช้าข้ามคืนโดยเจตนา — เพื่อให้มีเวลาแทรกซึมลงรูพรุนและรอยร้าวขนาดเล็กในคอนกรีตให้ลึกที่สุดก่อนฟอร์มตัวเป็นฟิล์ม ไม่ใช่แค่เคลือบผิวบางๆ

03

1K เปิดฝาพร้อมใช้

ส่วนผสมเดียว ไม่ต้องผสมตัวเร่ง ไม่ต้องตวงอะไรทั้งนั้น เปิดฝาแล้วทาได้เลย — ตัดโอกาส Human error หน้างานทิ้งไป 100%

04

ยืดหยุ่น + เหมาะงานภายใน

ฟิล์มโพลีเมอร์ไม่แข็งเปราะ รับการขยับตัวของโครงสร้างได้ ไม่แตกซ้ำง่ายๆ / กลิ่นน้อย Low VOC ทำงานในห้องนอน ห้องใต้ดินได้ และจบงานด้วยการฉาบแต่งหรือทาสีทับได้ตามปกติ

STRAIGHT TALK — ความจริงที่ต้องพูด

กันซึมจากด้านในคือโจทย์ที่โหดที่สุดของงานกันซึม —
ตัวช่วยดีแค่ไหน ก็ต้องเตรียมผิวเป็น

1KSINGLE COMPONENT · เปิดฝาพร้อมใช้

เริ่มด้วยความจริงที่ร้านกันซึมไม่ค่อยอยากพูด: การซ่อมน้ำซึมจากด้านใน (Negative Side) คือการซ่อมที่ "ผิดหลัก" ตั้งแต่ต้น — วิธีที่ถูกต้องตามหลักวิศวกรรมคือไปกันน้ำที่ฝั่งที่น้ำเข้า (Positive Side) ให้แรงดันน้ำช่วยกดฟิล์มแนบผิว การมาบล็อกจากด้านในคือการยืนสู้กับแรงดันน้ำที่ดันฟิล์มออกตลอดเวลา มันคือทางเลือกสุดท้ายจริงๆ สำหรับหน้างานที่ออกไปแก้ข้างนอกไม่ได้เท่านั้น เช่น ผนังร่วมทาวน์โฮม คอนโด ห้องใต้ดิน — ถ้าหน้างานของคุณยังออกไปซ่อมด้านนอกได้ ให้ไปซ่อมด้านนอกก่อนเสมอ DeepSeal เกิดมาเพื่อวันที่คุณไม่มีทางเลือกนั้นแล้ว และเราจูนมันมาให้รอดในสนามที่โหดที่สุดนี้โดยเฉพาะ

พูดตรงๆ ก่อนขาย: หัวใจของระบบนี้คือการเปิดผิวให้ถึงคอนกรีตเปลือย — สีเก่า ปูนฉาบ คราบน้ำมัน ต้องขัดลอกออกให้หมดเพื่อเปิดรูพรุนให้น้ำยาแทรกลงไปได้ลึกจริง ขี้เกียจขั้นนี้ขั้นเดียว น้ำยาดีแค่ไหนก็ได้แค่เคลือบผิว ไม่ได้ฝังตัวในโครงสร้าง

อีกเรื่องที่บอกกันตรงๆ: ฟิล์มที่ได้เป็นฟิล์มใสอมเหลือง ไม่ใช่สีขาวสวยพร้อมโชว์ — และเนื้อโพลีเมอร์ระบบนี้โดนแดดสะสมนานๆ จะเหลืองขึ้น ตัวนี้จึงเกิดมาเพื่องานภายในอาคาร และเราแนะนำให้ฉาบแต่งหรือทาสีทับหลังแห้งสนิทเสมอ — ซึ่งมันทำได้สบายอยู่แล้ว นั่นคือจุดขายของมัน

กติกาเหล็ก

ห้ามผสมตัวเร่ง ทินเนอร์ หรือสารใดๆ เพิ่มเด็ดขาด — ระบบนี้จูนมาจบในกระป๋องแล้ว ของแปลกปลอมทุกหยดคือตัวแปรที่ทำระบบพัง

วิธีใช้งาน

จบบนหน้านี้ครบทุกตัวเลข — หัวใจอยู่ที่การเปิดผิวปูนกับความใจเย็นตอนรอเซ็ตตัวข้ามคืน สองอย่างนี้ทำครบ น้ำหยุดจริง

  1. เปิดผิวให้ถึงคอนกรีตเปลือย

    ขัดลอกสีทับหน้า ปูนฉาบ คราบน้ำมัน และสิ่งสกปรกออกให้หมดจนถึงชั้นคอนกรีตจริง — ขั้นที่สำคัญที่สุดของทั้งระบบ เพราะน้ำยาต้องแทรกลงรูพรุนของปูนให้ลึกที่สุด

    ถึงคอนกรีตเปลือยเท่านั้น

  2. เช็คความชื้น — ห้ามมีน้ำขัง

    พื้นผิวควรแห้งหรือชื้นหมาดเพียงเล็กน้อย — ห้ามมีน้ำขังในบริเวณที่จะทาโดยเด็ดขาด ถ้ายังมีน้ำไหลซึมอยู่ให้จัดการระบายก่อน

  3. ซ่อมรอยร้าวใหญ่ให้เต็มก่อนเสมอ

    กติกาตายตัวของงานเคลือบทุกระบบ: รอยร้าวกว้างหรือรอยแตกบิ่นใหญ่ ให้สกัดเปิดร่องแล้วอุดซ่อมให้เต็มเรียบด้วยวัสดุซ่อมอย่าง FillerAce รอแห้งเรียบร้อยแล้วค่อยทา DeepSeal ทับ

    ซ่อมรอยร้าวก่อน → ค่อยเคลือบ

  4. เปิดฝา — ทาได้เลย

    ส่วนผสมเดียวพร้อมใช้ ใช้แปรงหรือลูกกลิ้งทาได้ทันที ห้ามผสมตัวเร่งหรือสารละลายใดๆ เด็ดขาด — ทาน้ำยาให้ชุ่มบริเวณที่มีปัญหา เน้นรอยต่อ มุมห้อง และแนวรอยร้าวเล็ก ให้น้ำยาซึมลงเนื้อปูนเต็มที่

    ไม่ต้องผสมอะไรทั้งนั้นแปรง / ลูกกลิ้ง

  5. ผิวพรุนจัด — ทารอบสองตัดขวาง

    สำหรับพื้นผิวที่พรุนสูงมาก ทารอบที่สองในทิศทางตัดขวางกับรอบแรกได้ โดยทาตอนที่รอบแรกเริ่มหมาด — รอบสองเป็นทางเลือก แต่พื้นที่เสี่ยงสูงเราแนะนำ

    รอบสอง: ทาตอนรอบแรกเริ่มหมาด

  6. ปล่อยเซ็ตตัวข้ามคืน 12–24 ชม.

    ช่วงนี้คือหัวใจ: น้ำยากำลังฝังตัวและทำปฏิกิริยากับโครงสร้างเพื่อสร้างแรงยึดเกาะสูงสุดในการต้านแรงดันน้ำ — ห้ามใจร้อน อย่าเพิ่งโดนน้ำ อย่าเพิ่งทำงานทับ

    เซ็ตตัว 12–24 ชม. (ข้ามคืน)

  7. แห้งสนิทแล้ว — ฉาบแต่ง / ทาสีทับได้

    รอให้แห้งสนิทสมบูรณ์ก่อน แล้วเดินงานขั้นต่อไปได้ตามปกติ ทั้งฉาบแต่งผิวและทาสีทับหน้า — แนะนำให้ปิดทับเสมอโดยเฉพาะจุดที่โดนแสง เพราะฟิล์มระบบนี้โดน UV สะสมนานๆ จะเหลืองขึ้น (ความแข็งแรงไม่ลด แค่เรื่องความสวย)

    ทาสีทับ = จบสวย
⚠ ความปลอดภัย: สวมถุงมือและเลี่ยงการสัมผัสน้ำยาโดยตรง / ทำงานในพื้นที่อากาศถ่ายเทสะดวก — งานห้องใต้ดินหรือมุมอับ จัดพัดลมระบายอากาศช่วยเสมอ
ปิดฝาให้แน่นทันทีหลังใช้: เนื้อน้ำยาเซ็ตตัวด้วยปฏิกิริยากับความชื้น — เปิดฝาทิ้งไว้ ความชื้นในอากาศจะทำให้เนื้อในกระป๋องเสื่อมสภาพ / เก็บในที่ร่ม แห้ง เลี่ยงแดดและความร้อนโดยตรง
