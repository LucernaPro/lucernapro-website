เว็บไซต์สินค้าของ **บริษัท ลูเซอน่า จำกัด (LucernaPro)** — static site ย้ายจาก Wix มา GitHub + Cloudflare

# 🔴 อ่านก่อนทำอะไรทั้งสิ้น — สำหรับ Claude ที่เพิ่งเปิดเซสชันใหม่

โปรเจกต์นี้ทำงานแบบ **full-auto**: เจ้าของ (คุณ Pist / ตี๋เล็ก) **ไม่แตะ terminal เลย**
Claude เป็นคน pull / แก้ / commit / push เองทั้งหมด เจ้าของมีหน้าที่ QA อย่างเดียว

**เซสชันใหม่ทุกครั้งต้องทำ 4 ขั้นนี้ก่อนพิมพ์ตอบอะไรยาวๆ:**

### 1. Clone repo (public อ่านได้โดยไม่ต้องใช้ token)
```
git clone https://github.com/LucernaPro/lucernapro-website.git
```
> token จำเป็นตอน **push** เท่านั้น — ถ้าเจ้าของยังไม่ได้ให้มา ให้ทวงก่อนเริ่มงาน

### 2. อ่าน `SPEC.md` ให้จบ
เป็น **session memory ตัวจริงของโปรเจกต์ และชนะโพยที่เจ้าของแนบมาในแชททุกกรณี**
ข้างในมีกฎเหล็ก (ห้ามละเมิด), doctrine ทั้งฟลีต, และบันทึกทุกด่านที่ทำไปแล้ว
**ถ้าโพยในแชทขัดกับ SPEC → เชื่อ SPEC แล้วทักเจ้าของ**

### 3. อ่านโพยของสินค้าที่จะทำ
```
notes/wix-archive/{slug}.md
```
มีครบ: ราคา · copy ไทยจาก Wix เดิม · ตัวเลขวิธีใช้ · ลิงก์ Shopee/Lazada (ตัดหาง tracking แล้ว)
· URL รูปต้นฉบับ · **ลิสต์ "ต้องเคาะ" ที่ยังค้าง**
> เนื้อหาชุดนี้ดึงมาจาก Wix ไว้ตอน 29 ก.ค. 2026 **ห้ามไปดึงจาก lucernapro.com ใหม่**
> (พอ cutover ไป Cloudflare เมื่อไหร่ หน้า Wix จะหายถาวร ไฟล์ชุดนี้คือสำเนาชุดสุดท้ายที่มี)

### 4. อ่าน template ต้นแบบก่อนเขียนหน้าใหม่
`/tilecoatpoly` คือ **certified golden master**
แต่ตัวที่ครบกฎล่าสุดและควรยกโครงมาใช้จริงคือ **`/pmma`** (หรือ `/masterseal`, `/heatshield`)
**ห้ามเขียนหน้าใหม่จากศูนย์เด็ดขาด — ยกโครงจากหน้าที่มีอยู่เสมอ**

## กฎที่พังบ่อยที่สุด (รายละเอียดเต็มอยู่ใน SPEC.md)

- **`git pull --rebase` ก่อน push ทุกครั้ง** — มีเซสชันคู่ขนานรันพร้อมกันบ่อย เคยชนกันมาแล้วหลายรอบ
- **verify ด้วย `git show origin/main:FILE` หลัง `git fetch`** ห้ามใช้ raw.githubusercontent (cache ช้า)
- **คำว่า "Epoxy" แบนทั่วฟลีต** ในเนื้อหาที่ลูกค้าเห็น
- **ห้ามเปิดชื่อ/รหัสวัตถุดิบและผู้ผลิต** (เช่น 0620, Aradur) — แต่ **ชื่อชนิดเคมี เช่น polysilazane เปิดได้**
- **ห้ามเชื่อมโยงสูตรระหว่างสินค้าของเราเอง** — ห้ามเขียน "ใช้เทคโนโลยีเดียวกับ X" / "สูตรพี่น้องกับ X"
- **ปุ่มสั่งซื้อต้องครบ 4 ช่อง** (Shopee / Lazada / แชทเพจ FB / Line) ก่อนถือว่าหน้าเสร็จ
- **How-to ต้องจบในหน้า** มีตัวเลขจริง (อัตราผสม เวลารอ) ห้ามลิงก์ออกไปคู่มือข้างนอก
- **ห้าม upscale รูปปลอม** และ **crop เป็น irreversible** — ถ้าไม่แน่ใจ ให้คงสัดส่วนต้นฉบับไว้
- **ไฟล์ที่ส่งให้เจ้าของชื่อ `index.html` เสมอ** ทั้งไทยและอังกฤษ (เจ้าของจัดโฟลเดอร์เอง)
- **ปิดด่านแล้วต้องอัปเดต `SPEC.md`** เป็น commit ปิดท้ายเสมอ

## โครงสร้างโฟลเดอร์

```
{slug}/index.html      หน้าสินค้าภาษาไทย
en/{slug}/index.html   หน้าสินค้าภาษาอังกฤษ
index.html             หน้า Home ไทย (catalog การ์ดสินค้า)
en/index.html          หน้า Home อังกฤษ
img/                   รูปทั้งหมด (webp) + วิดีโอที่โฮสต์เอง (mp4)
files/                 TDS / SDS (pdf)
_redirects             301 = เลิกขายถาวร / 302 = หน้ายังไม่ถูกสร้าง
SPEC.md                🔴 session memory ตัวจริง — อ่านก่อนเสมอ
notes/wix-archive/     โพยเนื้อหาจาก Wix เดิมของสินค้าที่ยังไม่ได้ทำ
notes/wix-archive/discontinued/   สินค้าที่เลิกขายแล้ว (เก็บไว้อ้างอิง)
```
