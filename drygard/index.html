สีทาบ้านทั่วไปเกิดมาเพื่อความสวย — พอเจอผนังที่ชื้นจริง มันก็ทำในสิ่งที่มันทำได้ คือพอง ลอก แล้วร่อนออกมาเป็นแผ่น ทาใหม่ปีหน้าก็ร่อนอีก / DryGard เป็นสีทาบ้านที่กันซึมอยู่ในเนื้อสี — เนื้อฟิล์มเป็นแบบยืดหยุ่น ยืดหดตามผนังได้โดยไม่แตกกรอบ ทนความชื้นได้ดีกว่าสีทาบ้านทั่วไปมาก และเกาะได้ตั้งแต่ผนังปูน ผนังฉาบ ผนังก่ออิฐ ไปจนถึงหลังคาเมทัลชีท / เปิดฝาทาได้เลย ไม่ต้องผสมอะไร ไม่ต้องลงรองพื้น สีเดิมที่ยังแน่นอยู่ก็ทาทับได้ทันที / บอกไว้ตรงนี้เลย: มันคือสีที่กันซึม ไม่ใช่วัสดุอุดรอยร้าว — รอยร้าวต้องซ่อมก่อน อย่าหวังให้สีปิดให้

ต่างจากสีทาบ้านทั่วไป ตรงไหน

จุดต่างอยู่ที่เนื้อฟิล์ม ไม่ใช่ความหนา — เราไม่ได้ขายสีที่ทาหนากว่าใคร เราขายสีที่อยู่ได้บนผนังที่ชื้น

01

กันซึมอยู่ในเนื้อสี ไม่ใช่คำโฆษณาต่อท้าย

สีทาบ้านทั่วไปกันน้ำได้แค่ระดับฝนสาดผ่านๆ พอผนังชื้นสะสมจริงจัง ความชื้นก็ดันฟิล์มจนพองแล้วลอกออกมาเป็นแผ่น / เนื้อ DryGard ออกแบบมาให้ทนความชื้นโดยตรง — น้ำผ่านเข้าเนื้อผนังได้ยากกว่า และไม่พองไม่ลอกง่ายเหมือนสีทั่วไป นั่นคือทั้งหมดของสินค้าตัวนี้

02

ยืดหยุ่น เลยไม่แตกลายงาตามผนัง

ผนังบ้านขยับตลอดเวลา — ร้อนขยาย เย็นหด ฟิล์มสีที่แข็งกรอบจึงแตกลายงาตามในที่สุด / เนื้อ DryGard เป็นแบบยืดหยุ่น (elastomeric) ยืดหดตามผนังได้โดยตัวฟิล์มไม่แตก อายุงานบนผนังที่โดนแดดสลับฝนทั้งปีจึงยาวกว่า / แต่ย้ำให้ชัด: "ตัวมันไม่แตก" คนละเรื่องกับ "ปิดรอยร้าวที่มีอยู่แล้ว" — อ่าน STRAIGHT TALK ข้อ 02

03

เปิดฝาทาได้เลย — ไม่ผสม ไม่รองพื้น

ไม่มีตัวเร่ง ไม่มีส่วน A ส่วน B ไม่ต้องเจือน้ำ คนให้ทั่วถังแล้วทาได้ทันที / และไม่ต้องลงรองพื้นในงานปกติ — ตัวมันเองเกาะผนังปูน ผนังฉาบ ผนังก่ออิฐ ไปจนถึงหลังคาเมทัลชีทได้ / สีเดิมที่ยังแน่นดี ทาทับได้เลย ไม่ต้องขูดออกทั้งบ้าน

04

กันเชื้อรา เช็ดคราบง่าย และสะท้อนความร้อนในตัว

ผิวฟิล์มแน่นทำให้คราบเกาะยากและเช็ดออกง่ายกว่าสีด้าน พร้อมสารกันเชื้อราในสูตรสำหรับบ้านเมืองร้อนชื้น / ในเนื้อสียังผสมสารสะท้อนความร้อนอยู่ด้วย ช่วยลดความร้อนที่ผิวผนังได้ระดับหนึ่ง — แต่ถ้าโจทย์หลักของคุณคือลดความร้อนโดยตรง อ่าน STRAIGHT TALK ข้อ 05 ก่อน เราจะบอกตรงๆ ว่าควรใช้ตัวไหน

STRAIGHT TALK — สิ่งที่คนขายสีไม่ค่อยบอก

ตัวนี้เก่งจริงในสนามของมัน แต่มันมีสนามที่ไม่ใช่ของมัน อยู่หลายอัน อ่านให้จบก่อนกดสั่ง จะได้ไม่เสียเงินฟรี

01 · มันคือสีทาบ้าน ไม่ใช่สีทาพื้น

DryGard เกิดมาเพื่อผนังและหลังคา — พื้นผิวที่ไม่มีใครเดินย่ำ / ฟิล์มยืดหยุ่นแบบนี้ไม่ทนการเสียดสี เอาไปทาพื้นที่คนเดินหรือรถวิ่ง เดี๋ยวก็ถลอกเป็นทางแล้วดำเก็บคราบ / งานพื้นคือคนละสินค้ากันเลย ดู สีทาพื้น Epoxy-PU

02 · อย่าซื้อเพราะหวังให้มันปิดรอยร้าว

ข้อนี้เราอยากพูดให้ชัดที่สุดในหน้านี้ — เนื้อสีมันไม่ได้หนาขนาดนั้น มันคือสี ไม่ใช่วัสดุอุด / รอยลายงาบางมากๆ ระดับที่เล็บสะกิดไม่เข้า ฟิล์มยืดหยุ่นพอจะคลุมไว้ได้บ้าง แต่แค่นั้นจริงๆ / รอยที่เห็นเป็นเส้นชัด หรือแยงเล็บเข้าไปได้ ต้องซ่อมให้เต็มก่อนเสมอ — ทาสีทับรอยร้าวเปล่าๆ เดี๋ยวรอยเดิมก็โผล่กลับมาเหมือนไม่เคยทำอะไร / รอยร้าวผนังใช้ FillerAce และรอยเส้นผมต้องเจียรกรีดร่องให้เปิดก่อน ป้ายทับผิวเฉยๆ ไม่อยู่

03 · สีเดิมที่กำลังจะร่อน ทาทับไปก็ร่อนตาม

DryGard เกาะแน่นกว่าสีเดิมของคุณ — แต่มันเกาะได้แค่กับสิ่งที่มันไปเกาะ / ถ้าข้างล่างเป็นสีเก่าที่กำลังจะหลุดอยู่แล้ว วันหนึ่งมันก็หลุดออกมาพร้อมกันทั้งแผ่น / ตรงไหนที่เคาะแล้วกลวง ขูดแล้วออก ต้องขัดออกให้หมดก่อน ตรงไหนที่ยังแน่นดี ทาทับได้เลย

04 · ถ้าน้ำดันมาจากด้านหลังผนัง ทาด้านนอกไม่จบ

ผนังติดดิน ผนังห้องใต้ดิน ผนังที่ชื้นขึ้นมาจากพื้น หรือน้ำในดินดันเข้ามาจากอีกฝั่ง — นั่นคือแรงดันน้ำจากด้านตรงข้าม (negative side) ซึ่งจะดันสีทุกยี่ห้อให้พองออกจากผนังในที่สุด ไม่เว้นตัวนี้ / งานแบบนั้นต้องแก้ที่เนื้อผนังก่อนด้วย DeepSeal แล้วค่อยทาสีทับ

05 · สะท้อนความร้อนได้ แต่ไม่ใช่ตัวชูโรงเรื่องนี้

ในเนื้อสีมีสารสะท้อนความร้อนอยู่จริง และช่วยได้ระดับหนึ่ง — แต่เฉดสีที่คุณเลือกมีผลมหาศาลกับเรื่องนี้ ยิ่งเฉดเข้ม ค่าสะท้อนยิ่งหายไป / ถ้าโจทย์หลักของคุณคือลดความร้อนใต้หลังคาให้ได้จริงจัง ตัวที่ทำงานนั้นโดยตรงคือ HeatShield (สีขาว มีผลทดสอบค่าสะท้อนจากสถาบันจริง) — DryGard คือสีทาบ้านที่กันซึม แล้วได้เรื่องความร้อนแถมมา ไม่ใช่กลับกัน

06 · ผนังที่ไม่มีปัญหาความชื้น สีธรรมดาก็พอ

ต่อตารางเมตรแล้วตัวนี้ยังแพงกว่าสีทาบ้านทั่วไปอยู่ดี / ถ้าผนังบ้านคุณแห้งดี ไม่เคยพอง ไม่เคยลอก แล้วอยากทาสีใหม่เพราะเบื่อสีเดิม — ไปซื้อสีทาบ้านธรรมดาเถอะครับ เราขายของให้คนที่มีปัญหา ไม่ได้ขายให้ทุกคน

อยากกันซึมแต่ไม่อยากเปลี่ยนสีผนัง? ถ้าผนังคุณสีสวยอยู่แล้วและแค่อยากได้ชั้นกันน้ำคลุมทับ ตัวที่ตอบโจทย์คือ AquaShell — ใสไม่มีสี ทาทับสีเดิมได้ ไม่เปลี่ยนหน้าตาบ้าน

วิธีใช้งาน

ตัวเลขจริงครบทุกขั้นอยู่ตรงนี้ ไม่ต้องไปเปิดคู่มือที่ไหนอีก

เช็คผนังก่อน — แห้ง สะอาด แน่น

ผนังต้องแห้งสนิท ไม่มีฝุ่น ไม่มีคราบเกลือขาว ไม่มีตะไคร่ / ผนังใหม่ที่เพิ่งฉาบเสร็จต้องปล่อยให้ปูนบ่มตัวก่อน อย่ารีบทาทับปูนที่ยังชื้นอยู่ / ผนังเก่าที่มีสีเดิม: เคาะและขูดหาจุดที่กลวงหรือร่อน ขัดออกให้หมด ส่วนที่ยังแน่นดีปล่อยไว้ ทาทับได้

ซ่อมรอยร้าวให้เต็มก่อน — ขั้นนี้ข้ามไม่ได้

อย่าหวังให้สีปิดรอยร้าวแทนการซ่อม รอยที่เห็นเป็นเส้นชัดหรือแยงเล็บเข้าได้ ต้องอุดให้เต็มก่อนทาสีเสมอ — ใช้ FillerAce / รอยเส้นผมต้องใช้ใบเจียรกรีดร่องให้เปิดก่อนแล้วค่อยอุด ป้ายทับบนผิวเฉยๆ เดี๋ยวก็หลุด / รอยต่อยากๆ อย่างแผ่นสมาร์ทบอร์ดหรือผิวลื่นใช้ DeepStick

ผนังที่ชื้นหนักตลอดเวลา — ลงรองพื้นก่อน

งานปกติไม่ต้องรองพื้น ทา DryGard ลงไปได้เลย / แต่ถ้าเป็นผนังที่โดนความชื้นหนักแทบตลอดเวลา เช่น ด้านที่ฝนสาดประจำ ผนังใกล้พื้นดิน หรือมุมที่ไม่เคยแห้งเลย — ให้ลง Marine Guard เป็นรองพื้นก่อนหนึ่งชั้น แล้วค่อยทา DryGard ทับ จะจบปัญหาได้สมบูรณ์กว่ามาก

เปิดฝา คนให้ทั่วถัง — แล้วทาได้เลย

ไม่ต้องผสมอะไรทั้งนั้น ไม่มีส่วน A ส่วน B ไม่ต้องเจือน้ำ / คนให้เนื้อสีเข้ากันทั่วถังจริงๆ ก่อนใช้ (เนื้อหนักจะนอนก้นถังตอนตั้งทิ้งไว้) / ห้ามผสมน้ำเพื่อยืดปริมาณเด็ดขาด — เจือน้ำ = ฟิล์มบางลง = ทิ้งความสามารถในการกันซึมที่คุณจ่ายเงินซื้อมาไปทั้งดุ้น / ทาด้วยแปรงหรือลูกกลิ้งได้ทั้งคู่

รอบที่ 1 — ทาให้เต็มเนื้อสม่ำเสมอ

ทาให้เนื้อสีเต็มและสม่ำเสมอทั้งผืน อย่าให้มีจุดบางจุดหนา / ทาไล่ไปทีละแปลง อย่าปล่อยให้ขอบสีแห้งคาไว้แล้วค่อยกลับมาต่อ จะเห็นรอยต่อ

เว้นระหว่างรอบ 2 ชั่วโมง / รอบสองให้ทาตัดขวางทิศทางของรอบแรก (รอบแรกกลิ้งขึ้น-ลง รอบสองกลิ้งซ้าย-ขวา) จะปิดจุดบางที่ตามองไม่เห็นได้หมด / ต้องทาให้ครบ 2 รอบ รอบเดียวไม่ใช่ระบบกันซึม เป็นแค่สีทาบ้านแพงๆ

หลังรอบสุดท้าย ทิ้งไว้ 8–12 ชั่วโมง

ครบ 8–12 ชั่วโมง ถือว่าพร้อมใช้งาน / ช่วงนี้อย่าให้โดนน้ำและอย่าเอาอะไรไปพิงหรือขูด / ห้ามทาถ้าฝนกำลังจะมา — ฟิล์มที่ยังไม่เซ็ตตัวเจอฝนสาดคือเสียของทั้งรอบ

ล้างเครื่องมือทันทีตอนสียังไม่แห้ง

ล้างแปรง ลูกกลิ้ง ถาดสี ด้วยน้ำทันทีขณะที่สียังเปียก / ปล่อยให้แห้งคาเครื่องมือเมื่อไหร่ ฟิล์มยืดหยุ่นแบบนี้ล้างออกยากมาก — อย่าลองดี

สรุปเวลาแบบสั้นๆ: ทา 2 รอบ · เว้นต่อรอบ 2 ชม. · หลังรอบสุดท้าย 8–12 ชม. พร้อมใช้งาน · 1 กก. ≈ 5 ตร.ม. ครบ 2 รอบ · ไม่ต้องผสม · ไม่ต้องรองพื้น (ยกเว้นผนังชื้นหนักตลอดเวลา)
