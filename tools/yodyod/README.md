## 1. ตัวละคร

- **ชื่อ:** หยดหยด (ทางการ, ใช้บนป้าย/ในเกม) · ในแคปชันเรียก "น้องหยดหยด" ได้
- **เป็นใคร:** พนักงานใหม่ของ LucernaPro ตำแหน่ง "ผู้ช่วยตามหาอาวุธลับ" —
  พาลูกค้าหาสินค้าที่ใช่ในเกม /finder และเป็นครูสอนเรื่องบ้านในซีรีส์ "หยดหยดสอน"
- **รูปร่าง:** หยดน้ำสีฟ้า สวมหมวกนิรภัยสีเหลือง แก้มชมพู ยิ้มเสมอ มีแขนข้างเดียวไว้โบก/ชี้
- **นิสัย/น้ำเสียง:** สุภาพ ลงท้าย "ครับ" เป็นกันเอง อธิบายของยากให้ง่าย ไม่ขายของโต้งๆ
- **บทพูดตัวอย่าง:** "สวัสดีครับ! ผมหยดหยด", "จิ้มจุดที่มีปัญหาบนบ้านได้เลยครับ — ลุย!"

## 4. ซีรีส์ "หยดหยดสอน" (คลิปความรู้)

- **สูตร:** หนึ่งคลิป = หนึ่งความจริงเรื่องบ้าน · 15-22 วิ · แนวตั้ง 1080×1920 30fps
- **โครง 5 ฉาก:** (1) เปิดด้วยปริศนา/อาการที่ลูกค้าเจอ 2-3 วิ → (2-3) เฉลยด้วยภาพผ่า/ซูม →
  (4) ทางแก้หนึ่งบรรทัด → (5) เฟรมปิดประจำซีรีส์
- **เฟรมปิดมาตรฐาน (ห้ามเปลี่ยนโดยไม่ถามเจ้าของ):** พื้นน้ำลึก+ฟอง / หยดหยดโบกมือ scale 3.6 กลางจอ y≈520 /
  ป้ายทอง "หยดหยดสอน EP.x" (540×104 y1050) / ปุ่มส้ม "lucernapro.com" (740×118 y1230) — แค่นี้ ไม่มีบรรทัดอื่น
- **เฟรมแรกต้องเห็นภาพจริงทันที** — ห้ามเปิดคลิปด้วย fade จากดำ (เฟรม 1 = thumbnail บนบางแพลตฟอร์ม)
- **ไม่มีเสียงในไฟล์** — เผื่อจังหวะให้พากย์ทับ (ลูกชายเจ้าของพากย์) เขียนบทพากย์จับเวลาต่อฉากให้ทุกครั้ง
- **ตัวหนังสือในคลิป:** ใหญ่ (หัว 60-80px) สั้น คำเน้นใช้ทองเข้ม #E8A200 — กลุ่มเป้าหมายวัยแว่น 35-60+
- แคปชันคลิปความรู้: ไม่ใส่ลิงก์ (ให้เฟรมปิดทำหน้าที่) + ติดแฮชแท็ก #หยดหยดสอน ทุกตอน
- **EP.1 (เผยแพร่แล้ว):** "ยาแนวคือฟองน้ำ" — น้ำมุดร่องยาแนวไม่ได้มุดกระเบื้อง / ตัวเจนเนอเรเตอร์: `gen_ep1.py`
- **EP.2 (ผลิตแล้ว รอเจ้าของ QA/เผยแพร่):** "รางผุ ไม่ใช่เวรกรรม" — ทาเคลือบตั้งแต่รางยังใหม่ / ตัวเจนเนอเรเตอร์: `gen_ep2.py` / คู่กับแคมเปญรางน้ำ+เคส /post/gutter-protective-coating
- **คิวหัวข้อถัดไป:** น้ำใส≠น้ำปลอดภัย (ด่างปูน/บ่อปลา), ทำไมทากันซึมแล้วยังรั่ว, ผสม 2:1 ห้ามกะด้วยตา,
  กระเบื้องเงาคือศัตรูของสี — เนื้อหาต้นทางอยู่ในหน้า STRAIGHT TALK ของเว็บ

## 5. ท่อผลิต (ทำซ้ำได้ทุก session)

```bash
# 1) เตรียมเครื่อง (ทุก session ใหม่)
apt-get install -y librsvg2-bin              # ffmpeg มีอยู่แล้ว
mkdir -p ~/.fonts && cd ~/.fonts && for f in Mitr-Regular Mitr-Medium Mitr-SemiBold; do
  curl -sL -O "https://raw.githubusercontent.com/google/fonts/main/ofl/mitr/$f.ttf"; done && fc-cache -f

# 2) ดึงเครื่องมือจาก repo นี้
cp tools/yodyod/gen_frames.py tools/yodyod/gen_ep1.py /home/claude/

# 3) เขียน gen_epX.py ตอนใหม่ (import ของกลางจาก gen_frames: mascot, droplet, bubbles, easing)
python3 gen_epX.py                            # สร้าง SVG ทีละเฟรม
ls f_*.svg | xargs -P8 -I{} sh -c 'rsvg-convert -w 1080 -h 1920 {} -o $(basename {} .svg).png'
ffmpeg -framerate 30 -i f_%04d.png -c:v libx264 -crf 19 -pix_fmt yuv420p -movflags +faststart out.mp4
```

วินัยการทำงาน: เล่าโครงฉาก+บทพากย์ให้เจ้าของเคาะก่อน render จริง / QA ด้วย preview
เฟรมสำคัญ (rsvg-convert -w 270) ก่อน rasterize เต็ม / เจ้าของ = คนตัดสินความอ่านง่ายบนมือถือ
