กาวตะปู SwiftSet
เปิดฝา ปาด ติด — ไม่ต้องใช้ปืนยิง

กาวตะปูทั่วไปมาเป็นหลอดแข็งๆ ที่ต้องมีปืนยิงถึงจะใช้ได้ ใช้ไม่หมดก็แข็งคาหลอด / SwiftSet เป็นกาวตะปูสูตรน้ำรุ่นใหม่ — ไร้กลิ่น รักษ์สิ่งแวดล้อม ยึดเกาะแน่น มาในกระปุกที่แค่เปิดฝาแล้วใช้เกรียงปาดได้เลย เหลือก็ปิดฝาเก็บไว้ใช้ต่อ / เหมาะกับงานง่ายๆ ทั่วไป — ติดวัสดุน้ำหนักเบาเข้ากับผนังแทนการเจาะ เช่น บัวผนัง คิ้ว ไม้ระแนงตกแต่ง แผ่นไม้บังตา หรือวัสดุตกแต่ง / งานหนักมากและงานอันตราย ห้ามใช้ — งานรับน้ำหนักต้องใช้พุกและสกรูยึดเชิงกล

สั่งซื้อ / สอบถาม fทักแชทเพจ ถามได้ก่อนซื้อ

ทำไมต้อง SwiftSet

กาวตะปูที่ตัดปืนยิงออกจากสมการ — เหลือแค่เปิดฝากับเกรียงอันเดียว

01

ไม่ต้องใช้ปืนยิง — อุปสรรคใหญ่สุดของมือใหม่หายไป

กาวตะปูแบบหลอดต้องซื้อปืนยิงเพิ่ม ใช้แรงบีบ และคุมแนวกาวยาก / SwiftSet มาเป็นกระปุก เปิดฝา ใช้ไม้พายหรือเกรียงตักแล้วปาดลงบนวัสดุได้เลย คุมปริมาณง่าย ใช้เหลือปิดฝาเก็บได้ ไม่แข็งคาหลอด

02

สูตรน้ำ ไร้กลิ่น ทำงานในบ้านได้สบาย

สูตรน้ำ (water-based) ไร้กลิ่นฉุน รักษ์สิ่งแวดล้อม — ปาดในห้องนอน ห้องนั่งเล่น คอนโด ได้โดยไม่ต้องหนีกลิ่นออกจากห้อง

03

ยึดเกาะแน่น — ติดแทนการเจาะ

ออกแบบมาเพื่อติดวัสดุน้ำหนักเบาเข้ากับผนังโดยไม่ต้องเจาะ — บัวผนัง คิ้ว ไม้ระแนงตกแต่ง แผ่นไม้บังตา แผ่นตกแต่งผนัง / ผนังไม่เป็นรู ถอนคืนห้องเช่าก็สบายใจ

04

ซื้อเยอะมี Bulk pack สำหรับผู้รับเหมา

งานติดตั้งวัสดุตกแต่งจำนวนมาก มีแบบ Bulk pack ไม่มี Package สำหรับผู้รับเหมาโดยเฉพาะ — ทักแชทเพจคุยราคาได้เลย

วิธีใช้งาน

จบบนหน้านี้ครบทุกขั้น — หัวใจคือผิวต้องสะอาด และวัสดุหนักต้องมีเทปช่วยประคองจนกาวแห้ง

  1. เตรียมพื้นผิวให้สะอาด

    เช็ดฝุ่น คราบน้ำมัน หรือสิ่งสกปรกออกจากทั้งผนังและหลังวัสดุที่จะติดให้เรียบร้อย — คราบพวกนี้คือตัวกั้นไม่ให้กาวจับผิวจริง

    ผิวสะอาดไร้คราบมัน

  2. เปิดฝา ตักกาวด้วยไม้พายหรือเกรียง

    ไม่ต้องใช้ปืนยิง — เปิดฝากระปุกแล้วใช้ไม้พายหรือเกรียงตักกาวออกมาได้เลย

    ไม่ต้องใช้ปืน

  3. ปาดกาวลงบนหลังวัสดุ

    ปาดกาวให้ทั่วด้านหลังของวัสดุที่ต้องการติด — อย่าปาดบางเกินไป ให้เนื้อกาวพอที่จะสัมผัสผนังได้เต็มหน้า

    ปาดให้ทั่วอย่าบางเกิน

  4. กดวัสดุแนบผนังให้แน่น

    กดวัสดุเข้ากับผนังให้แน่นทั่วทั้งแผ่น เพื่อให้เนื้อกาวสัมผัสได้ทั่วถึง

    กดให้แน่น

  5. วัสดุหนัก — ใช้เทปกาวช่วยประคอง

    หากวัสดุมีน้ำหนักมาก ใช้เทปกาวช่วยประคองไว้จนกว่ากาวจะแห้ง อย่าปล่อยให้กาวรับน้ำหนักเองตั้งแต่ยังเปียก

    เทปช่วยประคอง

  6. รอกาวแห้งสนิท ~24 ชั่วโมง

    ปล่อยทิ้งไว้ประมาณ 24 ชั่วโมง (เร็ว–ช้าตามอุณหภูมิและความชื้นหน้างาน) ระหว่างนี้อย่าขยับหรือฝืนรับน้ำหนัก

    ~24 ชม.

  7. ลอกเทปออก — จบงาน

    เมื่อกาวแห้งและวัสดุยึดแน่นดีแล้ว จึงค่อยลอกเทปกาวออก

    เช็กก่อนลอก
⚠ ขอพูดตรงๆ — SwiftSet เกิดมาเพื่องานง่ายๆ ทั่วไปเท่านั้น: ติดบัวผนัง คิ้ว ไม้ระแนงตกแต่ง แผ่นตกแต่งน้ำหนักเบา — งานประเภทนี้คือบ้านของมัน / งานหนักมากและงานอันตราย ห้ามใช้เด็ดขาด ไม่ว่าจะเป็นชั้นวางที่ต้องรับของ ตู้แขวนผนัง ราวจับ กระจกบานใหญ่ อุปกรณ์ที่คนต้องพิงหรือดึง หรืออะไรก็ตามที่ตกลงมาแล้วมีคนเจ็บ — งานพวกนี้ต้องใช้พุกและสกรูยึดเชิงกลเสมอ จะใช้กาวช่วยเสริมก็ได้ แต่ห้ามให้กาวรับน้ำหนักลำพัง / ไม่แน่ใจว่างานของคุณหนักไปไหม ส่งรูปมาถามในแชทก่อนซื้อ เราตอบตรงๆ ถ้าไม่เหมาะเราบอกว่าไม่เหมาะ
